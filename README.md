# stack-demo

A simple Terraform Stack Component Configuration demonstrating how to publish and consume a Stack component from the Terraform Enterprise Private Registry.

## Description

This component provisions a simple `null_resource` using the HashiCorp Null provider. It is intended as a minimal example for learning Terraform Stacks and the Private Registry.

## Requirements

- Terraform Stacks (supported Terraform version)
- HashiCorp Null Provider `~> 3.2`
